# Air Quality Index (AQI) Prediction using Machine Learning

This project focuses on predicting the Air Quality Index (AQI) using historical air
pollution and weather data. Supervised machine learning regression models are used
to analyze the relationship between pollutant concentrations and AQI values.

The project is implemented as part of an academic coursework and demonstrates the
complete machine learning workflow including data preprocessing, model training,
evaluation, and visualization.

---

## 🔍 Problem Statement

To develop a supervised machine learning regression model that predicts AQI based on
air pollutant levels such as PM2.5, PM10, NO₂, CO, and O₃, along with temperature and
humidity data, in order to support environmental monitoring and early analysis.

---

## 🧠 Approach

- Used historical air quality and weather datasets
- Performed data preprocessing and exploratory analysis
- Trained multiple regression models for AQI prediction
- Evaluated model performance using RMSE and R² metrics
- Visualized results using static plots

---

---

## 📊 Output

- AQI prediction values
- Model evaluation metrics
- Data visualizations showing pollutant relationships
